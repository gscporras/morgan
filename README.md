
# MORGAN

**Personal Intelligence System**

MORGAN is an open-source personal intelligence system designed to help people understand, organize, and improve their lives.

## Vision

Build a personal AI companion that understands its user over time, preserves personal knowledge, assists with decision-making, and interacts with the digital and physical world.

## Principles

- Privacy first
- User-owned data
- Open source
- Modular architecture
- Provider-independent AI
- Human-controlled autonomy

## Status

Early development.
