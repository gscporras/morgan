
# MORGAN Memory Design

## Memory categories

- Identity: stable user preferences and characteristics.
- Episodic: events and experiences.
- Semantic: concepts and learned knowledge.
- Factual: explicit facts about people, projects and situations.
- Temporal: changes and historical states.

## Memory requirements

Every memory should support:

- Unique identifier
- Content
- Category
- Source
- Creation timestamp
- Confidence
- Verification status
- Validity period
- Corrections and deletion

## Principles

- User-owned data.
- Traceable sources.
- No silent assumptions.
- Editable and deletable memories.
- Embeddings must be reproducible.
