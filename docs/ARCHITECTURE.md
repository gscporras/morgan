
# MORGAN Architecture

## Overview

MORGAN is a modular, open-source personal intelligence system.

## Core domains

- Conversation: manages interactions with the user.
- Memory: stores and retrieves personal knowledge.
- Context: builds relevant context for each interaction.
- Orchestration: coordinates AI providers and internal capabilities.
- Actions: executes authorized tools and operations.
- Life: manages goals, routines and personal organization.
- Home: integrates with personal devices and home automation.

## Architectural principles

- Modular monolith initially.
- Local-first data ownership.
- Cloud infrastructure is optional.
- AI provider independence.
- Explicit authorization for sensitive actions.
- Persistent and portable data.
